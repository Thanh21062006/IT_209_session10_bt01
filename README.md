# Bài tập: Phân tích kiến trúc Container vs VM

## Chức năng
- REPORT.md: Phân tích kỹ thuật lý do chuyển đổi kiến trúc.
- checker.py: Script Python để kiểm tra cấu hình Docker trên hệ thống.

## Hướng dẫn chạy
1. Đảm bảo bạn đã cài đặt Docker và đã thêm user vào group docker (để không cần sudo).
2. Chạy script kiểm tra:
   python3 checker.py
